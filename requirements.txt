# DEMASCAS — Python Dependencies (Tool Server only)
# Install with: pip install -r requirements.txt
#
# The C++ daemon handles audio capture (PortAudio), STT (whisper.cpp),
# streaming LLM (libcurl → MLX), and TTS (Kokoro / macOS say) natively.
# Python only runs the tool server that the daemon calls over HTTP.
#
# DEMASCAS ships WITHOUT a language model.  Plug in any local runtime
# (Ollama, LM Studio, llama.cpp, MLX, Jan) with:  python main.py setup

# PDF summarization (text extraction; summary uses the MLX text server)
PyPDF2

# File-system watcher (optional)
watchdog

# HTTP client (tool server internals, agents, LLM calls)
requests

# Environment variables
python-dotenv

# Web browsing (Capability 2)
ddgs
beautifulsoup4

# Persistent memory — ChromaDB RAG (Capability 3)
chromadb

# Tool micro-service for C++ daemon (Polyglot Architecture)
flask

# Array maths (sensors/vision)
numpy

# Hardware profiling for sizing the plug-in LLM (CPU/RAM/battery on macOS,
# Windows, Linux).  Optional — OS-native fallbacks are used without it.
psutil

# Coordinate clicks / typing / scrolling for the VLM vision fallback (macOS only)
pyautogui; sys_platform == "darwin"

# Optional legacy backend: if installed, PDF summaries fall back to Ollama
# when the MLX server is unreachable.
# ollama
